# Neon Vibe App

A tiny neon, vibe-coded web toy: glowing UI, interactive particles, and synthy sound feedback — all in a single static page.

## Features

- **Interactive particles**: a canvas background that reacts to movement/interaction.
- **Synth sounds**: subtle audio cues to match the “neon cyber” feel.
- **“Vibe” easter egg**: a small hidden/bonus behavior triggered by the right input/sequence.

## Getting started

No build step, no dependencies.

1. Clone this repository (or download the folder).
2. Open `index.html` in your browser.

That’s it.

## Project structure

- `index.html` — page markup
- `styles.css` — neon styling
- `app.js` — particles + interactions + sound
